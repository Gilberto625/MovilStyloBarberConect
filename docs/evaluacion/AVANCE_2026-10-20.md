## Hallazgos de este sprint

El detalle está en `docs/evaluacion/REGISTRO_ERRORES.md`. Lo urgente:
1. **ERR-02 (backend, PM02):** `GET /api/citas/politica-pago/?cliente_id=` no valida que el id sea del usuario autenticado. Además, la app manda el id de Django y la vista espera el `usuario_id` de negocio. **No se corrigió:** necesita aprobación, porque la web usa el mismo endpoint.
2. **ERR-03 (backend, PM02):** `CitasView._resolver_usuario_negocio_id` puede resolver a otra persona. **No se corrigió.**
3. **ERR-01 (app):** el diálogo de cobro de secretaría usaba controladores ya liberados. **Corregido** en `fix/secretaria-cobro-dialogo`, con una prueba que falla antes del arreglo y pasa después.
4. **ERR-04 (entorno):** con SQLite la API de negocio no funciona. Se montó PostgreSQL local y una semilla. Falta corregir la guía de entorno local del workspace.
